# MG4
## Devlog


The FloatAnimation script makes the fish food move up and down automatically. The Start() method runs once when the game begins and sets the initial values for the animation. The Update() method runs every frame and controls the movement of the food. The _up variable is a boolean that decides which direction the food moves. When _up is true, the food moves up, and when it is false, the food moves down. The _timer variable keeps track of time and helps decide when the food should switch directions. The movement speed controls how fast the food moves. By using these variables and methods together, the script makes the food float up and down repeatedly.
